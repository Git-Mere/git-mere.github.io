A Discord bot that runs multiple functional modes (bidirectional translation, grounded web search) per channel, configured live via slash commands without restarts. Channel settings, LLM provider fallback, and anti-hallucination constraints are all handled at the framework level so individual handlers stay provider-agnostic.
